# Google & Bing Search Console Setup

## 1. Google Search Console

### Step 1 — Add Property
1. Go to https://search.google.com/search-console
2. Click **Add property** → choose **URL prefix**
3. Enter `https://agribuyx.com`

### Step 2 — Verify Ownership (Meta tag method)
1. Choose **HTML tag** verification
2. Copy the verification code (looks like `abc123xyz`)
3. In Vercel: Project → Settings → Environment Variables
4. Add: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` = `abc123xyz`
5. Redeploy the site
6. Return to Search Console → click **Verify**

### Step 3 — Submit Sitemap
1. In Search Console left sidebar: **Sitemaps**
2. Enter: `https://agribuyx.com/sitemap.xml`
3. Click **Submit**
4. Status should show "Success" after Google fetches it

### Step 4 — Request Indexing
For new product pages:
1. In Search Console: **URL Inspection**
2. Paste a product URL e.g. `https://agribuyx.com/products/bypel-1-organic-biopesticide-550e84`
3. Click **Request Indexing**

---

## 2. Bing Webmaster Tools

### Step 1 — Add Site
1. Go to https://www.bing.com/webmasters
2. Click **Add a site** → enter `https://agribuyx.com`

### Step 2 — Verify (Meta tag method)
1. Choose **Meta tag** verification
2. Copy the value (not the full tag — just the `content` attribute value)
3. In Vercel: add `NEXT_PUBLIC_BING_SITE_VERIFICATION` = paste value
4. Redeploy → click **Verify**

### Step 3 — Submit Sitemap
1. In Bing Webmaster: **Sitemaps**
2. Submit: `https://agribuyx.com/sitemap.xml`

---

## 3. Sitemap & Robots URLs

| URL | Purpose |
|---|---|
| `https://agribuyx.com/sitemap.xml` | Full sitemap — products, blog, categories |
| `https://agribuyx.com/robots.txt` | Crawl rules |

Both are dynamically generated by Next.js Pages Router API files.

---

## 4. Monitoring

- **Coverage report**: Search Console → Indexing → Pages — shows which pages are indexed
- **Performance**: Search Console → Search results — shows clicks, impressions, CTR per page
- **Rich results**: Search Console → Enhancements — shows Product rich result errors/warnings
- **Core Web Vitals**: Search Console → Experience → Core Web Vitals — page speed signals
